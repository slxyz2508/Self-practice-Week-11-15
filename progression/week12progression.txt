asynchronous กับ syncronous คือรูปแบบของการทำของโปรแกรม โดยที่ asynchronous คือการทำงานแบบรอให้เสร็จสามารถตั้งเวลาได้ ทำให้โปรแกรมเกิด
การรอให้ฟังกชันก่อนหน้าเสร็จก่อนจึงทำต่อไปได้ โดยไม่เกิดการคลาดเคลื่อน
Promise คือ object ที่ใช้จัดการงานที่ทำแบบ asynchronous หรือ งานที่ ไม่ได้เสร็จทันที เช่น การดึงข้อมูลจากเซิร์ฟเวอร์, อ่านไฟล์, setTimeout เป็นต้น
มีสถานะ 3 แบบหลัก:
Pending , Fulfilled , Rejected ซึ่งมีประโยชน์การลดการใช้ callback function
ใน JavaScript fetch คือ ฟังก์ชันสำหรับดึงข้อมูล จาก server หรือ API โดยมัน 
ส่งกลับค่าเป็น Promise ซึ่งทำให้เราสามารถใช้ .then() หรือ async/await ในการจัดการข้อมูลเมื่อโหลดเสร็จ
